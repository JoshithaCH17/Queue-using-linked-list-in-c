# Queue Using Linked List in C

A menu-driven C program implementing
a queue using a singly linked list.

## Features
- Enqueue
- Dequeue
- Peek
- Display

## Concepts Used
- Queue (FIFO)
- Linked List
- Structures
- Pointers
- Dynamic Memory Allocation

## How to Run

Compile:
gcc queue_linked_list.c -o queue_linked_list

Run on Windows:
.\queue_linked_list.exe

## Language
C
